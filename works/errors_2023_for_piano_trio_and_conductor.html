Errors (2023)
for Piano Trio and Conductor

EN

“Errors” is a satirical work that transforms HTTP status codes into musical language, mocking the unplayable notation, systemic contradictions, and inefficient rehearsal culture of contemporary composers. Each movement is based on a real error code and musically reinterprets the message it conveys.

1. HTTP 400 Error: Bad Request
This movement mirrors what many composers already do – placing completely unplayable demands on performers. Notes out of reach, unplayable registers, and technically impossible instructions are presented all at once.

2. HTTP 403 Error: Forbidden
This movement translates the absurdity of unnecessary conducting into music. As the piece begins, the conductor appears on stage, only to have the baton taken away and be escorted off. It satirizes the over-involvement of conductors in small ensembles, highlighting the irony of control where none is needed. The music continues freely without a conductor.

3. HTTP 404 Error: Not Found
This movement musically interprets the idea of “Page Not Found.” Lasting exactly 4 minutes and 4 seconds, the score contains nothing but the text “404 Page not found.”

4. HTTP 502 Error: Bad Gateway
This final movement parodies a misconnected stage system. At the end of the piece, musicians exit not through the usual backstage doors, but through emergency exits or random pathways, each in their own direction. It reflects how even the ending of a performance can be riddled with errors.

DE

‘Errors’ ist ein satirisches Werk, das HTTP-Statuscodes in musikalische Sprache übersetzt. Es nimmt die unspielbare Notation, systemische Widersprüche und ineffiziente Probenkultur moderner Komponist aufs Korn. Jeder Satz basiert auf einem realen Fehlercode und interpretiert dessen Aussage musikalisch neu.

1. HTTP 400 Error: Bad Request
Dieser Satz ist, wie viele Partituren der Gegenwart, voller unausführbarer Anweisungen. Nicht erreichbare Töne, zu große Intervalle, unspielbare Register – alles ist enthalten.

2. HTTP 403 Error: Forbidden
Hier wird die Überflüssigkeit des Dirigierens thematisiert. Kaum hat der Dirigent die Bühne betreten, wird ihm der Taktstock entzogen und er wird hinausgeleitet. Die Szene karikiert die übermäßige Kontrolle durch Dirigent bei kleinen Ensembles. Die Musik verläuft anschließend frei und ohne Leitung.

3. HTTP 404 Error: Not Found
Dieser Satz interpretiert das Konzept „Seite nicht gefunden“ musikalisch. Er dauert exakt 4 Minuten und 4 Sekunden. Die Notenblätter zeigen lediglich die Aufschrift „404 Seite nicht gefunden“.

4. HTTP 502 Error: Bad Gateway
Im letzten Satz verlassen die Musikerinnen nicht den üblichen Bühnenausgang, sondern gehen durch Notausgänge oder falsche Türen – jeder für sich. Das symbolisiert ein fehlerhaftes System auch im Abgang.

FR

« Errors » est une œuvre satirique qui traduit les codes d’erreur HTTP en langage musical. Elle se moque des partitions injouables, des absurdités systémiques et de l’inefficacité des répétitions dans la musique contemporaine. Chaque mouvement s’s’inspire d’un code d’erreur réel et en propose une réinterprétation musicale.

1. HTTP 400 Error: Bad Request
Ce mouvement illustre ce que de nombreux compositeurs font déjà : imposer aux musiciens des demandes tout simplement irréalisables. Sons hors de portée, tessitures inaccessibles, instructions techniquement impossibles.

2. HTTP 403 Error: Forbidden
Ce mouvement dénonce l’inutilité du chef d’orchestre dans certains contextes. Dès l’entrée du chef, sa baguette lui est retirée, et il est escorté hors de scène. Il s’agit d’une critique de l’intervention excessive des chefs dans des formations réduites. La musique se poursuit librement, sans direction.

3. HTTP 404 Error: Not Found
Ce mouvement traduit l’idée de « Page introuvable » en musique. Il dure exactement 4 minutes et 4 secondes. La partition ne contient qu’un seul message : « 404 Page non trouvée ».

4. HTTP 502 Error : Bad Gateway
Ce dernier mouvement met en scène une sortie chaotique : les musiciens ne quittent pas la scène par l’arrière, mais empruntent des sorties de secours ou des portes inattendues, chacun suivant son propre chemin. Cela symbolise un système de concert défaillant jusqu’à sa fin.

KR

《오류들》(Errors)은 HTTP 상태 코드들을 음악적 언어로 전환하여, 현대 작곡가들의 연주 불가능한 표기, 시스템적 모순, 비효율적인 리허설 문화를 비꼬는 풍자적 작품이다. 각 악장은 실제 존재하는 오류 코드를 기반으로 하며, 각 코드가 내포한 메시지를 음악적으로 재구성한다.

1. HTTP 400 Error : Bad Request
이 악장은 많은 작곡가들이 이미 그렇게 하듯이 연주자에게 절대 수행할 수 없는 요구를 던지는 방식으로 구성되어 있다. 손이 닿을 수 없는 음, 음역을 벗어난 기보 등 불가능한 기술적 지시들이 혼재되어 있다.

2. HTTP 403 Error : Forbidden
403 악장은 ‘지휘의 불필요함’을 음악적으로 풀어낸다. 연주가 시작되자마자 지휘자는 무대에 등장하지만, 곧 지휘봉을 빼앗기고 퇴장당한다. 이는 몇 명 되지 않는 앙상블에 굳이 개입하려는 지휘자의 존재를 풍자하며, 리허설이나 연주 중 생기는 불필요한 통제의 아이러니를 꼬집는다. 실제로 이 악장은 지휘 없이도 자유롭게 흘러간다.

3. HTTP 404 Error : Not Found
‘404’는 ‘페이지를 찾을 수 없음’을 음악적으로 해석한 악장이다. 이 악장은 정확히 4분 04초 동안 진행된다. 악보에는 ‘404 페이지를 찾을 수 없습니다’가 표기되어 있는 것이 전부다.

4. HTTP 502 Error : Bad Gateway
502 악장은 무대와 무대 밖의 ‘게이트’가 잘못 연결되어 있는 상황을 풍자한다. 곡의 마지막, 연주자들은 전통적인 퇴장 경로가 아닌 비상구 혹은 엉뚱한 문을 통해 각자 다른 방식으로 퇴장한다. 이는 공연이라는 시스템의 종료 과정조차도 오류투성이일 수 있음을 암시한다.
